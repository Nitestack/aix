# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
Entries are generated by [release-plz](https://release-plz.dev) from
[Conventional Commits](https://www.conventionalcommits.org/).

## [1.0.0](https://github.com/get-aix/aix/releases/tag/v1.0.0)

First versioned release, and the first release published to crates.io as
[`aix-rs`](https://crates.io/crates/aix-rs). The installed binary is still `aix`.

Earlier builds were published only as a rolling `latest` GitHub release from
`main`. That release is replaced by versioned `vX.Y.Z` releases plus a rolling
`nightly` prerelease.
